`office/web_form_mapper` deterministically inspects web forms, extracts inputs and hidden security state, maps contact identities (via `addressbook.yaml` `legal_profile`), generates human-verifiable diffs, and submits with explicit confirmation gates.

---

## Capabilities

- **Hidden State & Anti-CSRF Invariants**: Automatically extracts and preserves hidden tokens (`_csrf`, `authenticity_token`, ASP.NET `__VIEWSTATE`, `__EVENTVALIDATION`) so sessions and submissions do not fail.
- **Unified Address Book Integration**: Integrates directly with `addressbook.yaml` `legal_profile` ([#408](https://github.com/ARPAHLS/skillware/issues/408)), supporting self-filing (`use_self: true`) and client corporate entity filings (`contact_id: "<id>"`).
- **Semantic Field Heuristics**: Tokenizes form metadata (camelCase, labels, placeholders, aria-labels) and aligns inputs with canonical tax, legal, and residential concepts.
- **Fail-Closed Anti-Bot Detection**: Immediately halts with `STATUS_BLOCKED` when encountering Cloudflare Turnstile, reCAPTCHA, hCaptcha, or WAF challenges to prevent agent loop lockups.
- **Multi-Engine Execution**:
  - `http_post`: Fast, deterministic HTTP POST dispatch with preserved tokens and local HTML receipt artifact.
  - `browser`: Headless Playwright automation dispatching synthetic input events (`input`, `change`, `blur`) for single-page applications (React, Vue, Angular).
- **Safety Triad**: `inspect` $\rightarrow$ `map` $\rightarrow$ `preview` $\rightarrow$ `submit` (requires `confirmed: true` when `dry_run: false`).

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `action` | `string` | No | Operation: `inspect`, `map`, `preview`, or `submit` (default: `inspect`). |
| `html_content` | `string` | No | Raw HTML content to parse offline (recommended for deterministic CI and local tests). |
| `url` | `string` | No | Target URL to fetch or submit against. |
| `payload` | `object` | No | Direct key-value dictionary to fill into the form. |
| `contact_id` | `string` | No | Contact ID from `addressbook.yaml` to autofill. |
| `use_self` | `boolean` | No | When true, resolves the operator's primary identity (`is_self: true`). |
| `form_profile_id` | `string` | No | Optional curated profile ID from `kb/form_profiles/`. |
| `form_index` | `integer` | No | Index of target form when multiple `<form>` elements exist (default `0`). |
| `fill_plan` | `array` | No | Field mapping plan generated by `map` to preview or submit. |
| `confirmed` | `boolean` | No | Must be `true` to execute live submission (`dry_run: false`). |
| `dry_run` | `boolean` | No | When true, simulates submission and writes payload artifact without network traffic (default: `true`). |
| `execution_engine` | `string` | No | Submission runner: `http_post` (default) or `browser`. |
| `output_dir` | `string` | No | Directory to write receipts and screenshots (defaults to context scratch directory). |

```python
import os

from google.genai import types
from skillware.core.env import load_env_file
from skillware.core.loader import SkillLoader

bundle = SkillLoader.load_skill("office/web_form_mapper")

tool = SkillLoader.to_gemini_tool(bundle)

html_fixture = "<form action='/submit' method='POST'><input name='name'/></form>"
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Inspect this web form and list required fields.",
    config=types.GenerateContentConfig(
        tools=[tool],
        system_instruction=bundle["instructions"],
    ),
)
for part in response.candidates[0].content.parts:
    if part.function_call:
        result = skill.execute(dict(part.function_call.args))
        print(result["status"])
```

## Chaining & Security Pipelines

In autonomous enterprise agent loops, `office/web_form_mapper` pairs with `security/deceptive_ui_guard` and `compliance/tos_evaluator`:

- **Preflight Surface Screening (`security/deceptive_ui_guard`)**: Screens unfamiliar forms for dark patterns, hidden opt-ins, or fake urgency before inspection occurs.
- **Deterministic Form Mapping (`office/web_form_mapper`)**: Extracts inputs, preserves hidden CSRF/ViewState tokens, maps fields from `addressbook.yaml` `legal_profile`, and produces diff tables.
- **Reference Chain (`secure_web_form_intake`)**: Defined in [`.skillware.yaml.example`](../../../.skillware.yaml.example) and demonstrated in [`examples/web_form_guard_chain_demo.py`](../../../examples/web_form_guard_chain_demo.py).

---

## Limitations

- **Interactive CAPTCHA / 2FA**: Automated submission will not attempt to bypass active Cloudflare Turnstile, reCAPTCHA, or SMS OTP challenges; it fails closed with `STATUS_BLOCKED`.
- **Stateless Single-Shot**: The skill executes bounded operations (`inspect`, `map`, `preview`, `submit`); it is not a long-running crawler or background scraper daemon.
- **Browser Extra Requirement**: The headless browser engine (`execution_engine: "browser"`) requires `pip install "skillware[office_web_form_mapper_browser]"` (Playwright). The baseline HTTP engine operates with zero heavy dependencies.

---

## Safety Constitution

1. **Explicit Confirmation**: Never submit sensitive PII, tax IDs, or company documents to an external endpoint without `confirmed: true`.
2. **State Integrity**: Always preserve hidden CSRF tokens and ASP.NET `__VIEWSTATE` invariants.
3. **Local Artifacts**: Save receipts, screenshots, and logs to local context scratch storage.
